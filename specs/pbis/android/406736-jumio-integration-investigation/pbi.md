## Description (from Azure DevOps)

Investigate the technical and product requirements to integrate Jumio into the Empower native app, based on the proposed Empower flow and Jumio screens.

The spike should evaluate how the Jumio identity verification experience can be launched from Empower, how the mobile SDK communicates with the backend, and what changes are required across Android app.

The outcome should provide enough information to estimate and plan the implementation PBIs, including any dependencies, SDK configuration, technical limitations, and open questions.
